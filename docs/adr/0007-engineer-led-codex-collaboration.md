# ADR-0007 — Engineer-led Development, Codex as Reviewer

Date: 2026-11-17
Status: **PROPOSED — OWNER APPROVAL REQUIRED** (requested working practice in conversation)

## Context
The solo engineer explicitly wants to design and implement source code personally and deepen Senior AI Engineering skill; autonomous AI code generation ("vibe coding") would undermine technical ownership.

## Decision proposed
- Human authors technical designs, code, tests, benchmark execution and release decisions.
- Codex reads, explains, challenges assumptions, reviews diffs, audits architecture/security, proposes tests, analyzes evidence and verifies only with explicit execution permission.
- Default tools/actions are read-only. Changes to source, dependencies, CI, deployments, Git refs, PRs or credentials need specific user authorization.
- Hint ladder: theory → targeted design suggestion → pseudocode → smallest code correction **only when requested**.
- Every ticket records design, implementation/test evidence, AI review findings, human decision and rollback. No code generated by Codex by default.
- AI must separate tested facts, hypotheses and unknowns; no claimed tests without logs.

## Consequences
Slower initial coding throughput but stronger learning, explicit responsibility and auditable decisions. Documentation changes can be delegated as scoped tasks without granting general code-edit rights.

## Tests
Review checkpoints and prompt instructions in docs/codex; PR descriptions expose executed checks vs NOT RUN; owner approves ADR before promoting it to accepted.
